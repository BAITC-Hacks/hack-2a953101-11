Исправлены два обнаруженных дефекта:

1. Поиск по коду 1С не работал во встроенном наборе: в нём код находится в `product_id`, а поле `internal_code` отсутствует. Поиск использует идентификатор при отсутствии отдельного кода; добавлены браузерные проверки рекомендаций и поставок. Данные и формулы расчёта не менялись.
2. Дополнительные тесты реального импорта собирали дубли MOQ из корня и каталогов, превышая лимит 12 книг. Исправлен выбор файлов в Go/browser tests, README уточняет использование одной копии MOQ. Сам импортёр не менялся.

Также добавлены HTTP- и браузерная проверки отказа для `.xls` без записи данных.

Для повторения полного набора с исходными книгами:

```sh
python3 scripts/import_supplier_workbooks.py
SUPPLIER_WORKBOOK_DIR="$PWD" SUPPLIER_IMPORT_FILE="$PWD/data/supplier-import.json" go test -race ./...
go vet ./...
go build -o bin/backend .
npm ci
npx playwright install chromium
npm run test:syntax
SUPPLIER_WORKBOOK_DIR="$PWD" SUPPLIER_IMPORT_FILE="$PWD/data/supplier-import.json" npm run test:browser
python3 -m unittest discover -s scripts -p 'test_*.py'
```

Playwright использовал установленную сборку Chromium для Ubuntu 24.04 с предупреждением о неподдерживаемой ОС.
